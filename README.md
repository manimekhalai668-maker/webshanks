# ⚔️ Shanks Code - Platform

A high-scale EdTech & Workshop platform featuring career tracks, live coding workshops, Razorpay payment processing, automated Google Meet dispatch, and PDF certificate issuance.

---

## 👥 Team Breakdown & Architecture

This repository is maintained by a 5-member team:
- **`client/`**: Frontend web application (React / Next.js, Tailwind CSS)
- **`server/`**: Backend API service (Node.js, Express, MongoDB, Razorpay, Nodemailer, PDFKit)

---

## 🚀 Backend Service (`server/`)

The backend is fully built, structured, and production-ready in [`server/`](file:///c:/Users/Lenovo/OneDrive/Documents/Desktop/shanks-code/server).

### Getting Started with the Backend:
```bash
cd server
npm install
npm run seed  # Populates sample programs, workshops, coupons, and test accounts
npm run dev   # Starts the server with nodemon on http://localhost:5000
```

Refer to the detailed [Backend API Documentation](file:///c:/Users/Lenovo/OneDrive/Documents/Desktop/shanks-code/server/README.md) for endpoint signatures, request bodies, and admin workflows.
